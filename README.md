# William Byrd Baseball Throwing Program

Mobile-first field guide for William Byrd Terriers players and coaches. ENHANCE is the five-stage program. RAMP is the color progression. Common faults are a separate page.

Open `index.html`. ENHANCE stages are shareable as `#stage-1` through `#stage-5`. `#enhance` and `#stages` open the stage picker. `#ramp` and `#original` open RAMP. Fault write-ups are on `faults.html`. No build step.
