# William Byrd Baseball Throwing Program

Mobile-first field guide for William Byrd Terriers players and coaches. RAMP is Stage 1. ENHANCE is Stages 2–5. Common faults are a separate page.

Open `index.html`. `#stage-1`, `#ramp`, and `#original` open RAMP on Medium. `#light`, `#medium`, and `#hard` pick the RAMP day. `#stage-2` through `#stage-5` open those ENHANCE stages. `#enhance` and `#stages` open ENHANCE on Stage 2. Fault write-ups are on `faults.html`. No build step.
