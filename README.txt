SWVA ELEVATED THROWING PROGRESSION

Open index.html in a modern browser. All five demonstration videos, posters,
and key-move clips are included; there are no external fonts or video embeds.
No login, analytics, cookies, payment code, or build step is required.
Review marks use browser local storage only. No player data is sent anywhere.

For a phone-accessible site, publish the CONTENTS of this folder to a static
host such as Netlify, Cloudflare Pages, or GitHub Pages, with the owner's
approval. Keep the assets folder and relative paths unchanged. We have not
published these files or created a hosting account. Confirm permission to
redistribute the source demonstration videos before public publication.

LOCAL PREVIEW
  python3 -m http.server 8080 --directory /workspace/pitch/site
  Open http://localhost:8080 on this same computer.
A localhost address is not a public link and will not work on a remote phone.

PLAYER CONTROLS
- Play/pause and scrub/fullscreen with the native video controls.
- Replay key move jumps to the selected throwing action and loops it.
- Loop can be turned off; the key segment then stops at its end.
- Full video returns to the full demonstration from the start.
- Speed: 0.25x, 0.5x, 1x. Frame +/- pauses and steps 1/30 second.
- Standalone key-move MP4s are available beneath each video.
- Videos do not autoplay. Only one can play at a time.

COACH REVIEW BEFORE USE
The supplied deck's distances and color-specific sets are retained. The deck
has ambiguous wording ('after 5 rounds', a 6/9 check vs 6-10 throws for one
step). The expanded coach notes explain that the coach must define those
limits; do not add test throws or assume five full circuits.
No exact plyo-ball weights are inferred. Coach approval, youth-appropriate
workload and individualized supervision are required. Stop for pain.
Added cues are teaching prompts, not medical advice or video transcriptions.
Stretch and Full have no source videos and are deliberately text-only.
